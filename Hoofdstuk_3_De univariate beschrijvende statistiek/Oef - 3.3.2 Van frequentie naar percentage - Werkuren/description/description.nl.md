Gebruik opnieuw de werkuren van acht deelnemers:

`20, 24, 24, 28, 32, 32, 32, 36`

De waarde **32 uur** komt drie keer voor.

**Leerdoel:** één absolute frequentie omzetten naar een proportie en een percentage.

Bereken:

1. de proportie voor 32 uur als `frequentie / totaal`;
2. het bijbehorende percentage als `proportie × 100`.

Rond beide antwoorden af op drie decimalen. Vul het percentage in zonder procentteken.
