Drie deelnemers werkten respectievelijk:

`20, 24, 28` uur.

**Leerdoel:** een getekende afwijking ten opzichte van het gemiddelde berekenen.

Bereken eerst het gemiddelde. Bereken daarna voor de deelnemer met **20 uur** de afwijking met:

`afwijking = waarneming - gemiddelde`

Een waarde onder het gemiddelde moet dus een negatieve afwijking krijgen.
