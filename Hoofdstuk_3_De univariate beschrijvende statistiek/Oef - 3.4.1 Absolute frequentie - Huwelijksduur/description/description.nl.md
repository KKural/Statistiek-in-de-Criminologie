Bij zes koppels werd de huwelijksduur in dagen geregistreerd:

`30, 60, 60, 90, 120, 120`

Huwelijksduur heeft een **ratiomeetniveau**.

**Leerdoel:** de absolute frequentie van één duur bepalen.

Hoe vaak komt een huwelijksduur van **60 dagen** voor?

Vul één getal in op de lege plaats in het codebestand.
