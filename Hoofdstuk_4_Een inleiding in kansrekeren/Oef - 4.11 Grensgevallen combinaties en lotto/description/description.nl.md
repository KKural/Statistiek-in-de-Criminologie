# Combinaties: grensgevallen en toepassing

Voor combinaties geldt:

$$\binom{n}{k}=\frac{n!}{k!(n-k)!}$$

Bereken:

1. $\binom{8}{0}$: op hoeveel manieren kan je geen enkel dossier uit acht dossiers kiezen?
2. $\binom{5}{5}$: op hoeveel manieren kan je alle vijf dossiers kiezen?
3. $\binom{41}{6}$: hoeveel lottoselecties van zes verschillende getallen uit 41 zijn mogelijk wanneer de volgorde niet uitmaakt?

Vervang de drie `???` door gehele getallen.
