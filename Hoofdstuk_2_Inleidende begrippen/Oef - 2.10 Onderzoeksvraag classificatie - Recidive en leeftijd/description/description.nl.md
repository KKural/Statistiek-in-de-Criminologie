**Leerdoel:** onderzoeksvragen classificeren door het aantal variabelen, de rol van elke variabele en de onderzoeksopzet te onderscheiden.

Kies bij elk onderdeel de beste optie.

1. De vraag luidt: “In welke mate voorspelt leeftijd de kans op recidive?” Welk type vraag is dit?

   1. univariaat beschrijvend;
   2. bivariaat beschrijvend;
   3. bivariaat verklarend;
   4. kwalitatief exploratief.

2. De vraag luidt: “Verschilt recidive tussen mannen en vrouwen?” Welke variabele is de afhankelijke variabele?

   1. geslacht;
   2. recidive;
   3. beide variabelen;
   4. er is geen afhankelijke variabele.

3. Een stad vergelijkt geweldsdelicten vóór en na de plaatsing van camera’s, zonder willekeurige toewijzing of controlegroep. Welke onderzoeksopzet past?

   1. gerandomiseerd experiment;
   2. quasi-experimentele voor-na-studie;
   3. univariaat overzicht;
   4. kwalitatief interviewonderzoek.

4. De vraag luidt: “Wat is de gemiddelde leeftijd van geregistreerde geweldsdaders?” Welk type vraag is dit?

   1. univariaat beschrijvend;
   2. bivariaat beschrijvend;
   3. bivariaat verklarend;
   4. experimenteel.

Vul in het antwoordbestand per onderdeel één optienummer in.
