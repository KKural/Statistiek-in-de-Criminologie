1. In ŷ = 10 + 3X1 + 2X2 is b1 = 3. Gebruik 1 = bij één eenheid meer X1 stijgt ŷ gemiddeld 3 bij constante X2; 2 = Y stijgt altijd exact 3; 3 = X2 stijgt 3; of 4 = het intercept stijgt 3.

3. De toets voor deze modelverbetering geeft p = 0.02. Gebruik bij α = 0.05 code 1 = significante verbetering of 2 = geen significante verbetering.
4. Een regressiemodel heeft F = 12.4 en p < 0.001. Gebruik 1 = het model verklaart significant meer variantie dan het nulmodel; 2 = elke coëfficiënt is significant; 3 = de residuen zijn normaal; of 4 = R² is gelijk aan 1.
